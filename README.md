# Cronograma Gantt NFCYa

Aplicación web para visualizar y exportar el cronograma de prácticas académicas del proyecto **NFCYa** mediante un diagrama de Gantt.

## Funcionalidades

* Visualización del cronograma por semanas.
* Organización de actividades por fases.
* Exportación del cronograma en:

  * Imagen
  * PDF
  * Excel

## Tecnologías

* HTML5
* CSS3
* JavaScript
* HTML2Canvas
* jsPDF
* ExcelJS

## Uso

Abrir el archivo HTML en un navegador web.

No requiere instalación ni configuración adicional.
